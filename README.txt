NOPRESSURE — MOTION PORTFOLIO

1. Put your MP4 files inside the videos/ folder.
2. Open index.html in a text editor.
3. Find:
   const projects = [
4. Add each video, for example:
   {title:"Nike Motion", src:"videos/nike-motion.mp4", poster:"images/nike.jpg"},
5. Upload the whole folder to a static host such as GitHub Pages, Netlify, or Vercel.

IMPORTANT:
The supplied Google Drive folder cannot be automatically turned into public streaming URLs by this static template. For reliable playback, download/copy the videos into /videos and host the website + videos together (or replace src with direct video URLs from a suitable video host).
